# splashywebsite

Static recreation of [splashyonline.com](https://splashyonline.com) for ongoing maintenance in Git.

## Structure

- `index.html` — single-page Splashy site
- `css/styles.css` — styles from the live site
- `js/main.js` — logo QR modal
- `images/logo.png` — live logo
- `images/SplashyQR.png` — QR for `https://www.splashyonline.com` (regenerated; live file was 404)
